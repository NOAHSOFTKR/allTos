# 지윤 이용약관

**최종 수정일:** 2026년 6월 24일

---

본 약관은 지윤(이하 "**본 서비스**")의 이용과 관련하여, **이용자**와 **개발자** 간의 권리, 의무 및 책임 사항을 규정합니다.

---

## 1. 서비스 개요

**본 서비스**는 GPT 기반 AI 대화 기능을 제공하는 Discord 봇으로, Lumina의 리뉴얼 버전입니다. TypeScript 기반으로 개발되었으며, AI 대화, 멀티 API 연동, 이벤트 기반 응답 시스템을 제공합니다. **본 서비스**를 이용함으로써 본 약관에 동의한 것으로 간주됩니다.

---

## 2. 개인정보 수집

**본 서비스**는 기능 제공을 위해 다음 정보를 수집합니다.

* Discord 사용자 ID 및 닉네임
* 서버(길드) ID 및 채널 ID
* AI 대화를 위해 입력된 메시지 내용

---

## 3. AI 기능 이용 안내

**본 서비스**는 OpenAI GPT API를 활용한 AI 대화 기능을 제공합니다.

* **이용자**가 입력한 메시지는 AI 응답 생성을 위해 외부 API(OpenAI)에 전달됩니다.
* AI가 생성한 응답은 사실과 다를 수 있으며, **본 서비스**는 AI 응답의 정확성을 보장하지 않습니다.
* AI 기능을 통해 불법적이거나 유해한 내용을 생성하려는 시도는 금지됩니다.

---

## 4. 금지 행위

* AI를 통한 허위 정보, 혐오 콘텐츠 생성 시도
* 봇을 통한 스팸 또는 과도한 API 요청
* 서비스 취약점 악용
* 타인을 사칭하거나 개인정보를 무단으로 입력하는 행위

---

## 5. 서비스 제한

**개발자**는 다음 경우에 서비스 이용을 제한할 수 있습니다.

* 약관 위반 행위 발생 시
* 시스템 과부하를 유발하는 과도한 AI 요청 시
* 외부 API 할당량 초과 시
* 서비스 유지보수 또는 업데이트 시

---

## 6. 면책 조항

**본 서비스**는 GPT API 응답, Discord API 장애, 또는 외부 서비스 문제로 인한 불편이나 손해에 대해 책임을 지지 않습니다. AI가 생성한 콘텐츠로 인해 발생하는 문제에 대한 책임은 해당 내용을 입력한 **이용자**에게 있습니다.

---

## 7. 약관 변경

본 약관은 변경될 수 있으며, 변경 사항은 본 페이지를 통해 고지됩니다.

# NOAHSOFT Account 개인정보처리방침

시행일: [확인 필요: 시행일]

Noahsoft(이하 "회사")는 NOAHSOFT 서비스 공통 계정인 NOAHSOFT Account(account.noahsoft.kr, 이하 "계정")를 운영하면서 아래와 같이 개인정보를 처리합니다. 계정에 연결해 쓰는 각 서비스(Noahsoft Store, TTSBot 등)의 개인정보 처리는 그 서비스의 방침을 따릅니다.

## 1. 수집하는 정보와 목적

| 구분                    | 항목                                                                                                                 | 목적                                                              | 보유 기간                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------- |

외부 계정을 연결할 때 외부 서비스가 알려주는 이메일 주소는 저장하지 않습니다. 이용자가 허용한 서비스가 요청할 때만 그때그때 외부 서비스에서 조회해 전달합니다(2절).

이름·휴대폰 번호와 이메일 주소는 본인 확인을 거친 값이 아니며, 이용자가 입력한 그대로 처리합니다.

## 3. 회사 서비스에 제공하는 정보

계정에 연동한 회사 서비스(Noahsoft Store, TTSBot 등)에는 이용자가 동의 화면에서 허용한 범위에서만 아래 정보를 제공합니다.

| 제공 정보                                         | 제공 조건                                                                                 |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 계정 식별자                                       | 이용자가 그 서비스와 연동을 승인했을 때                                                   |
| 사용자명                                          | 회사 서비스가 화면 표시를 위해 계정 식별자나 사용자명으로 조회할 때(연동 여부와 무관)     |
| 계정 이메일 주소, 이름, 휴대폰 번호               | 연동한 서비스가 요청하고 이용자가 항목별로 허용했을 때                                    |
| 이름·휴대폰 번호 저장·변경                        | 연동한 서비스가 요청하고 이용자가 항목별로 허용했을 때(그 서비스에서 이용자가 입력한 값) |
| 연결된 외부 계정의 정보(예: Discord 서버 목록)     | 연동한 서비스가 요청하고 이용자가 해당 연결의 이용을 허용했을 때                          |
| Minecraft 런처 로그인 토큰                        | 이용자가 고위험 권한으로 따로 확인하고 허용했을 때                                         |
| 개발자 콘솔의 계정 식별자                         | 이용자가 개발자 콘솔에서 NIA API 프로젝트·키를 만들거나 조회할 때(NIA API 운영 서비스로)   |

허용한 항목은 계정 페이지의 "계정 정보 제공"과 서비스 목록에서 항목별로 중단하거나 연동 자체를 해제할 수 있습니다. 해제하면 그 서비스는 더 이상 조회할 수 없습니다. 법령에 따른 요청이 있는 경우 외에는 위 목적을 벗어나 제3자에게 제공하지 않습니다.

## 5. 보유 기간과 파기

1절의 기간이 지나거나 처리 목적을 달성하면 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

계정 화면에는 아직 계정 삭제(탈퇴) 기능이 없습니다. 계정 삭제를 원하면 아래 문의처로 요청할 수 있고, 회사는 본인 확인 후 계정과 그에 딸린 정보(연결, 연동, 동의, 세션, 신뢰 기기, 감사 기록)를 함께 삭제합니다.

## 6. 이용자의 권리

이용자는 다음을 직접 하거나 아래 문의처로 요청할 수 있습니다.

- 열람: 계정 페이지에서 연결한 외부 계정, 연동한 서비스, 허용한 항목을 확인할 수 있습니다.
- 정정: 사용자명, 비밀번호, 이름·휴대폰 번호를 계정 페이지에서 바꿀 수 있습니다.
- 삭제·처리정지: 이름·휴대폰 번호를 지우고, 외부 계정 연결과 서비스 연동을 해제하고, 항목별 제공을 중단할 수 있습니다. 계정 삭제는 5절에 따라 요청합니다.

## 7. 안전성 확보 조치

- 비밀번호, 로그인 유지 토큰, 복구 코드, 재설정 토큰은 원문을 저장하지 않고 해시로만 보관합니다.
- 외부 계정 토큰과 인증 앱 비밀값은 암호화해 보관합니다.
- 서비스가 계정 정보를 조회하거나 저장하면 감사 기록을 남깁니다. 감사 기록에는 이름·휴대폰 번호 같은 값을 남기지 않고 항목 이름만 남깁니다.
- 2단계 인증과 신뢰 기기 관리를 제공합니다.

## 8. 쿠키

계정은 다음 쿠키만 사용합니다. 광고·추적 목적의 쿠키는 사용하지 않습니다.

- `noahsoft_refresh_token`: 로그인 유지(HttpOnly)
- `noahsoft_oauth_flow_*`, `noahsoft_oauth_return_*`, `noahsoft_link_flow_*`: 외부 계정 연결과 서비스 연동을 진행하는 동안 같은 브라우저인지 확인(10분)

# Noahsoft Store 개인정보처리방침

시행일: [확인 필요: 로그인 구매자 정보 미리 채우기(ns-store#29) 배포 공지일로부터 7일 뒤]

Noahsoft(이하 "회사")는 Noahsoft Store(이하 "스토어")를 운영하면서 아래와 같이 개인정보를 처리합니다. 원문은 [noahsoft.kr/tos/ns-store/pp](https://noahsoft.kr/tos/ns-store/pp)에서 관리됩니다.

## 1. 수집하는 정보와 목적

| 구분               | 항목                                                                                                                                                                               | 목적                                             | 보유 기간                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 회원 구매          | NS Account 사용자 ID, NS Account에 연결된 Discord 사용자 ID                                                                                                                        | 구매자 식별, 권한 부여, 1인 1회 쿠폰 판정        | 권한 만료 후 5년(전자상거래법상 거래 기록)                                              |
| 비회원 구매        | 이메일 주소                                                                                                                                                                        | 구매권 코드 안내, 주문 조회 본인 확인, 환불 안내 | 결제일로부터 5년                                                                        |

| 결제               | 주문번호, 상품, 금액, 결제 수단 종류, 결제대행사 결제 키, 승인/취소 시각, 결제대행사가 돌려준 결제 수단 요약(카드사, 카드번호 앞 6~8자리와 마스킹된 카드번호, 승인번호, 할부 정보) | 결제 승인·취소, 환불, 분쟁 대응                  | 5년                                                                                     |

| 자동 수집          | 접속 IP, 요청 시각, 브라우저 정보                                                                                                                                                  | 부정 사용 방지, 장애 대응                        | 90일                                                                                    |

(주1) 비회원 구매의 이메일 주소는 위 "비회원 구매" 항목에 따라 보관합니다. 결제창에 입력한 이름·휴대폰 번호와 회원의 이메일 주소는 스토어에 저장하지 않습니다.

(주2) 회원이 결제 화면에서 "다음 결제에도 이 이름·휴대폰 번호 사용"을 고르면, 입력한 이름·휴대폰 번호를 회원의 NS Account 계정에 저장합니다(2절). 저장하려면 회원이 NS Account에서 스토어에 저장을 허용해야 하며, 허용하지 않았거나 저장하지 못해도 결제는 그대로 진행됩니다. 저장된 값은 NS Account 계정 페이지에서 고치거나 지울 수 있고, 스토어에 대한 제공·저장 허용도 그곳에서 항목별로 중단할 수 있습니다.

전체 카드번호, 유효기간, CVC, 계좌번호 등 결제 수단 정보는 결제대행사(주식회사 포트원)와 결제사(주식회사 케이지이니시스)가 처리하며, 회사는 위 표의 결제 수단 요약 외에는 보관하지 않습니다.

## 2. 개인정보의 제3자 제공과 처리 위탁

| 받는 자                                           | 제공·위탁 항목                                                                                | 목적                                                             |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 주식회사 포트원                                   | 주문번호, 상품명, 금액, 구매자 이름·휴대폰 번호·이메일 주소                                   | 결제 승인·취소, 환불                                             |
| 주식회사 케이지이니시스                           | 포트원을 통해 전달되는 결제 정보(주문번호, 상품명, 금액, 구매자 이름·휴대폰 번호·이메일 주소) | 신용카드 결제 승인·취소                                          |
| NS Account(회사 자체 서비스, account.noahsoft.kr) | NS Account 사용자 ID, (회원이 고른 경우) 결제 화면에서 입력한 이름·휴대폰 번호                | 로그인, Discord 연결 정보 조회, 결제창 구매자 정보 저장(1절 주2) |
| TTSBot·aichat 등 회사의 서비스                    | 권한 종류, 기간, Discord 사용자/서버 ID                                                       | 구매한 권한을 해당 서비스에서 적용                               |

법령에 따른 요청이 있는 경우 외에는 위 목적을 벗어나 제3자에게 제공하지 않습니다.

## 3. 이용자의 권리

이용자는 자신의 주문·권한 정보를 스토어의 "내 권한"과 "주문 조회"에서 확인할 수 있고, 아래 문의처를 통해 열람·정정·삭제·처리정지를 요청할 수 있습니다. 다만 법령상 보관 의무가 있는 거래 기록은 보유 기간 동안 삭제되지 않습니다.

## 4. 안전성 확보 조치

- 구매권 코드는 원문을 저장하지 않고 해시와 암호화된 사본만 보관합니다.
- 결제 기록에는 결제창에 입력한 구매자 이름·휴대폰 번호·이메일 주소와 결제사의 거래 응답 원문을 남기지 않습니다.
- 회원 결제창 기본값은 데이터베이스에 저장하지 않고 계정별 임시 보관소(캐시)에 최대 10분만 둡니다.
- 결제대행사 비밀 키, 서비스 간 인증 키는 서버 환경 변수에만 보관합니다.
- 결제·권한 변경은 모두 감사 기록(누가, 언제, 무엇을)을 남깁니다.
- 세션 쿠키는 HttpOnly·서명 처리되어 위·변조를 확인합니다.

## 5. 쿠키

스토어는 로그인 상태 유지를 위한 세션 쿠키(`__Host-ns_store_session`)와 로그인 진행 확인용 임시 쿠키(`__Host-ns_store_login`)만 사용합니다. 광고·추적 목적의 쿠키는 사용하지 않습니다.

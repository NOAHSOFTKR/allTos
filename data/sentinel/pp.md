# Sentinel 개인정보처리방침

**최종 수정일:** 2026년 11월 7일

---

Sentinel(이하 "**본 서비스**")을 운영하는 노아소프트(이하 "**운영자**")는 이용자의 개인정보를 소중히 여기며 **개인정보보호법** 및 관련 법규를 준수합니다. 용어는 [이용약관](https://noahsoft.kr/tos/sentinel/tos) 제1조를 따릅니다.

**본 서비스**는 보안 플랫폼이므로, **본 서비스**를 직접 추가하지 않은 **서버 멤버**의 정보도 서버 관리자가 **본 서비스**를 추가한 서버 안에서 처리됩니다.

---

## 1. 수집하는 개인정보 항목

이용하는 기능과 서버 관리자의 설정에 따라 처리 항목이 달라집니다.

### 1-1. 보안 이벤트·사건 (서버 멤버 포함)

* **행위자·대상 정보:** Discord 사용자 ID, 행위자의 역할 ID와 권한. 행위자는 Discord 감사 로그로 확인된 경우에만 기록합니다.
* **멤버 상태:** 사용자 ID, 봇 여부, 역할 ID, 타임아웃 종료 시각, 서버 입장 시각, 계정 생성 시각, 멤버 인증 대기 여부
* **Discord 감사 로그 사본:** 실행자 ID, 대상 ID, 변경 전후 값, 감사 로그 사유 문구. 사유는 서버 관리자 등이 직접 입력한 자유 문구이며, 최대 512자까지 저장합니다.
* **사건·대응 기록:** 사건의 주요 행위자, 위험도 평가, 실행한 조치와 그 대상, 사건 상태 변경자

### 1-2. 입장 관리·인증 (신규 입장자)

* 입장·인증 상태와 그 변경 이력, 인증 시도 기록
* 웹 인증 토큰의 해시값과 인증 답안의 해시값. 토큰과 답안 원문은 저장하지 않습니다.
* 사용자 이름의 "형태" 해시값. 비슷한 이름으로 몰려오는 계정을 찾는 데 쓰며, 이름 원문은 저장하지 않습니다.
* 서버 관리자가 등록한 차단 목록(사용자 ID, 사유)
* 서버 멤버 신고 기록: 신고자 ID, 신고 대상 ID, 메시지 ID, 채널 ID, 분류, 처리 메모. **신고된 메시지 내용은 저장하지 않습니다.**
* **초대 게이트 외부 신호(서버 관리자가 켠 경우에만):** 초대 게이트 로그인 시 이용자의 Discord 가입 서버 목록을 확인합니다. 그 중 서버 관리자가 지정한 차단 대상 서버와 겹치는 **개수만** 기록하며, 가입 서버 목록 자체는 저장하지 않습니다.

### 1-3. 메시지 관련

* **메시지 본문은 저장하지 않습니다.**
* 스팸 탐지를 위한 메시지 내용 접근은 기본적으로 꺼져 있습니다. 서버 관리자 측 설정으로 켜진 경우에만, 메시지 내용을 즉시 다음 값으로 바꾼 뒤 원문을 버립니다.
  * 해시값과 길이
  * 링크의 해시값
  * Discord 초대 코드
  * `@everyone` 사용 시도 여부
* Discord AutoMod가 차단한 메시지의 내용도 저장하지 않습니다.

### 1-4. 서버 구조 스냅샷·증거

* 역할·채널·권한 설정·AutoMod 규칙·서버 설정. 멤버별 권한 덮어쓰기가 있으면 해당 멤버의 사용자 ID가 포함됩니다.
* 사건 증거 패키지: 위 기록에서 만든 사건 자료와 해시 체인. 표시 이름·프로필 정보·메시지 내용은 포함하지 않습니다.
* 메시지 기록, 멤버 목록과 멤버별 역할 배정, 초대 링크는 스냅샷 대상이 아닙니다.

### 1-5. 웹 대시보드·초대 게이트 로그인

* Discord 로그인 시 사용자 ID와 서버별 권한 등급(소유자·관리자·서버 관리 권한 여부)
* 로그인 세션 기록(세션 해시값, 생성·만료 시각)
* **Discord OAuth 토큰**
  * 대시보드 로그인용 토큰은 사용 직후 폐기하며 보관하지 않습니다.
  * 초대 게이트용 토큰은 서버 입장 처리에 필요한 동안만 암호화해 보관하고, 입장 처리 후 폐기합니다.
* **IP 주소:** 원문을 저장하지 않습니다. 요청 횟수 제한과 감사 기록을 위해 키를 사용한 해시값만 저장합니다.
* 브라우저 정보(User-Agent)와 브라우저 지문은 **본 서비스**가 수집하지 않습니다.

### 1-6. 운영자 활동·AI 분석

* **관리 감사 로그:** 명령·대시보드 작업을 한 사람의 ID, 작업 내용, 대상, 결과, IP 해시값
* **운영자 권한 기록:** 운영자 권한 부여 기록, 확인 절차 기록, 정책 변경 이력(변경자 포함)
* **AI 분석:** 요청자 ID, 질문(민감정보 마스킹 후 최대 512자), 분석 결과와 사용량
  * 분석에 보낸 원본 프롬프트와 AI 제공업체의 원본 응답은 저장하지 않습니다.
  * 관리자가 분류를 위해 붙여 넣은 메시지 원문도 저장하지 않습니다.

### 1-7. Sentinel Edge

**Sentinel Core에 저장되는 정보**

* Edge 장치 정보: 장치 ID, 공개키와 지문, Edge 봇의 사용자 ID, 승인·폐기한 사람의 ID, 최근 접속 시각
* Edge가 업로드한 보안 기록: 위 1-1과 같은 종류의 정보
* 상태 신호: Edge의 동작 상태와 버전 등 운영 정보. 개인정보는 포함하지 않습니다.

**고객 호스트에 저장되는 정보**

고객 호스트의 Edge 기록에는 다음이 들어 있습니다.

* 보안 이벤트, 행위자·대상 ID, 감사 로그 사유 문구
* 채널·역할 이름, 멤버 상태
* 사용자 이름은 원문이 아닌 "형태" 해시값으로만 기록합니다. Edge는 메시지 내용을 수집하지 않습니다.

## 2. 개인정보 이용 목적

1. 서버 파괴 행위·대량 입장 공격 탐지와 대응
2. 신규 입장자 인증과 위험도 평가
3. 서버 구조 기록과 서버 관리자 승인 기반 복구
4. 사건 기록, 증거 패키지 생성, 사건 사후 분석(AI 분석 포함)
5. 서버 관리자 인증과 권한 확인, 관리 작업의 감사 기록
6. Sentinel Edge 연동과 장애 기간 기록의 대조·반영
7. 오류·보안 사고 대응과 문의 응대

## 3. 개인정보 보유 기간

**본 서비스를 서버에서 제거해도 기록은 자동으로 삭제되지 않습니다.** 삭제를 원하면 제5조에 따라 요청해 주세요.

### 3-1. 자동으로 정리되는 기록

| 항목 | 보유 기간 |
|---|---|
| 서버 구조 스냅샷 | 기본 최대 30개·90일. 서버 관리자가 `/복구 보존`으로 조정할 수 있습니다. 사건·증거·복구 계획에 연결된 스냅샷과 고정한 스냅샷은 자동 정리 대상에서 제외됩니다. |
| AI 분석 결과 | 사건 요약·위험 설명·대응 제안은 90일, 메시지 분류와 질문은 30일 |
| 로그인 시작 정보 | 만료 후 1시간 이내 |
| 초대 게이트 OAuth 토큰 | 입장 처리 후 폐기, 미완료 시 만료되면 삭제 |
| 운영자 확인 절차 기록 | 만료 후 1시간 이내 |
| 자동 조치 실행 기록 | 48시간 |
| Edge 페어링 코드 | 10분(해시값만 보관) |

### 3-2. 자동 파기 기한이 없는 기록

다음 기록은 현재 자동 파기 기능이 구현되어 있지 않습니다.

* 보안 이벤트와 Discord 감사 로그 사본
* 사건·위험 평가·대응 기록
* 입장·인증 기록, 차단 목록, 신고 기록, 외부 신호 기록
* 대시보드 세션 기록
* 증거 패키지
* Edge 업로드 기록
* AI 질문·사용량 기록
* 관리 감사 로그
* 정책 변경 이력

이 기록은 다음 시점까지 보관합니다.

* 삭제 요청이 있을 때까지
* 파일럿 서비스가 종료될 때까지. 서비스 종료 시에는 법령상 보존 의무가 있는 기록을 제외하고 파기합니다.

**관리 감사 로그**는 변조를 막기 위해 데이터베이스 단에서 수정·삭제가 차단되어 있습니다. 그래서 삭제 요청이 있어도 이 기록은 지우지 못할 수 있습니다. 이 경우 그 사실과 사유를 안내합니다. 관리 감사 로그에는 IP 원문이 아닌 해시값만 들어 있습니다.

### 3-3. 고객 호스트의 Sentinel Edge 기록

* Sentinel Core가 수신을 확인한 기록은 기본 24시간 후 고객 호스트에서 정리됩니다. 고객 설정에 따라 1시간~90일입니다.
* 수신이 확인되지 않은 기록은 업로드될 때까지 남습니다.
* 연결 해제 시 `침해의심` 기간을 지정하면, 그 기간의 기록은 Sentinel Core에서 반영하지 않고 격리해 보관합니다.
* 고객 호스트의 격리 기록과 연결 해제 후 남은 데이터는 자동으로 삭제되지 않습니다. 고객이 직접 삭제해야 합니다.

## 4. 처리위탁 및 국외 이전

수집된 개인정보는 법령에 따른 경우를 제외하고 제3자에게 제공하지 않습니다. 다만 아래 기능을 위해 외부 업체를 이용합니다.

### 4-1. AI 분석: OpenAI, Anthropic

* **전송 시점:** 서버 관리자가 대시보드에서 AI 분석을 요청한 경우에만 전송합니다. 모든 메시지나 사건을 자동으로 보내지 않습니다.
* **전송 항목:**
  * 분석 대상 사건의 기록. Discord ID와 기록 ID는 `U1`, `C2` 같은 별칭으로 바꾸어 보냅니다. 토큰, 웹후크 주소, 이메일, 전화번호, IP 주소, 카드번호는 가린 뒤 보냅니다.
  * 관리자의 질문(최대 500자)
  * 관리자가 분류를 요청하며 붙여 넣은 메시지(최대 4,000자)
* **업체 소재 국가:** 미국. 실제 처리 지역과 업체 측 보관 기간은 각 업체의 정책과 계약 조건을 따릅니다.
* **본 서비스가 보관하는 범위:** 분석 결과만 제3조의 기간 동안 보관하며, 보낸 원본과 업체의 원본 응답은 보관하지 않습니다.

### 4-2. 웹 인증: Cloudflare Turnstile (Cloudflare, Inc.)

* 웹 인증 페이지를 열면 이용자의 브라우저가 Cloudflare의 인증 스크립트를 불러옵니다. 이때 Cloudflare가 봇 여부 판단을 위해 브라우저·접속 정보를 직접 처리할 수 있습니다.
* **본 서비스**는 인증 결과 토큰을 Cloudflare에 보내 검증만 하며, 이용자의 IP 주소를 Cloudflare에 전달하지 않습니다.
* **업체 소재 국가:** 미국. 처리 방식은 Cloudflare의 개인정보 정책을 따릅니다.

### 4-3. 국외 이전 관련 법정 사항

국외 이전에 관해 법령이 요구하는 사항(이전 항목, 국가, 일시·방법, 받는 자, 목적, 보유 기간)은 위에 적은 대로입니다. 변경되면 본 방침을 먼저 갱신합니다. 국외 이전을 원하지 않으면 다음 방법이 있습니다.

* **AI 분석:** 서버 관리자가 AI 분석을 요청하지 않으면 전송되지 않습니다.
* **웹 인증:** 웹 인증 페이지를 이용하지 않으면 됩니다. 다만 서버 관리자가 웹 인증을 입장 조건으로 정한 서버에서는 해당 서버의 인증을 마칠 수 없을 수 있습니다.

## 5. 이용자 권리

이용자는 다음을 요청할 수 있습니다. **본 서비스**를 직접 추가하지 않은 서버 멤버도 직접 요청할 수 있습니다.

* 개인정보 열람
* 정정·삭제
* 처리 정지
* 동의 철회

요청은 아래 개인정보 보호책임자 이메일 또는 Noahsoft Discord 서버로 보내 주세요. 본인 확인을 위해 Discord 계정 확인을 요청할 수 있습니다.

* **처리 기한:** 원칙적으로 **72시간 이내**에 처리합니다.
* **처리 방식:** 현재 이용자가 직접 기록을 지우는 기능은 없습니다. **운영자**가 요청을 확인한 뒤 직접 처리합니다.
* **예외:** 다음 경우에는 처리할 수 없는 범위와 사유를 안내합니다.
  * 법령상 보존 의무가 있는 기록
  * 제3조의 관리 감사 로그처럼 변조 방지를 위해 수정·삭제가 차단된 기록
  * 진행 중인 보안 사건의 조사에 필요한 기록
* 서버 관리자는 서버 단위 기록의 삭제를 요청할 수 있습니다.
* 고객 호스트에 있는 Sentinel Edge 기록은 **운영자**가 접근할 수 없으므로 고객이 직접 삭제해야 합니다.

## 6. 개인정보 파기 절차 및 방법

보유 기간이 지나거나 삭제 요청을 처리할 때, 전자적 기록은 복구할 수 없는 방법으로 삭제합니다. 증거 패키지 파일도 함께 삭제합니다.

## 7. 개인정보의 안전성 확보 조치

* 웹 인증 토큰, 인증 답안, 로그인 상태값, 세션, 페어링 코드, 운영자 CLI 토큰은 원문 대신 해시값으로 저장합니다.
* IP 주소는 키를 사용한 해시값으로만 저장합니다.
* 일시적으로 보관하는 OAuth 토큰과 로그인 검증값은 AES-GCM으로 암호화합니다.
* **대시보드 보안**
  * 세션은 최대 12시간, 1시간 동안 사용이 없으면 만료되며, 15분마다 갱신합니다.
  * Discord 권한을 30분마다 다시 확인합니다.
  * 모든 변경 요청에 CSRF 방어를 적용합니다.
* 관리 감사 로그와 증거 해시 체인은 추가만 가능하도록 설계해 변조를 막습니다.
* 서비스 로그에서 토큰 등 비밀값을 가립니다.
* **Sentinel Edge**
  * Edge 기록은 항목마다 AES-256-GCM으로 암호화해 저장합니다.
  * Sentinel Core와 주고받는 요청·응답은 Ed25519로 서명하고 검증합니다.
  * Sentinel Core와의 통신은 원칙적으로 HTTPS만 허용합니다(같은 호스트 안의 통신이거나 고객이 명시적으로 허용한 경우는 예외).

## 8. 쿠키

웹 대시보드와 초대 게이트는 로그인 유지를 위해 아래 쿠키를 사용합니다. 광고·분석용 쿠키는 사용하지 않습니다.

* `sentinel_session`: 로그인 세션, 최대 12시간
* `sentinel_login`, `sentinel_gate`: Discord 로그인 과정 보호, 10분

브라우저 설정으로 쿠키를 거부할 수 있으나, 이 경우 대시보드 로그인과 초대 게이트를 이용할 수 없습니다.

## Sentinel 개인정보 처리방침

> **초안 — 게시 전 NOAHSOFT Owner 승인 필요.** `[확인 필요]`로 표시한 항목이 모두 정해지기 전에는 이 문서를 병합(게시)하지 않습니다. 이 저장소는 파일이 병합되는 즉시 `noahsoft.kr/tos/sentinel/pp`에 노출됩니다.

NOAHSOFT(이하 "**회사**")는 Discord 서버 보안 서비스 Sentinel(봇, 대시보드, Sentinel Edge를 포함하며 이하 "**본 서비스**")을 제공하면서 **개인정보보호법** 등 관련 법령을 지킵니다. 이 방침은 본 서비스가 어떤 개인정보를 왜 처리하고, 언제 파기하며, 이용자가 어떤 권리를 가지는지 알려드립니다.

본 서비스는 Discord 서버 관리자가 서버에 설치해 사용합니다. 그래서 개인정보가 처리되는 사람은 두 부류입니다.

  * **서버 운영자:** 본 서비스를 설치하고 Discord 명령이나 대시보드로 관리하는 사람
  * **서버 멤버:** 본 서비스가 설치된 서버에 들어오거나 활동하는 사람(서버에 들어오기 전 웹 인증을 받는 사람 포함)

-----

### 1\. 처리하지 않는 정보

본 서비스는 다음 정보를 저장하지 않습니다.

  * Discord 메시지 원문, 사용자명, 아바타
  * 신고된 메시지의 내용
  * Discord OAuth refresh token
  * IP 주소 원문, 세션·인증 토큰 원문 (모두 키를 사용한 해시로만 보관합니다)

-----

### 2\. 처리하는 개인정보 항목과 목적

#### 2.1 서버 운영자

| 항목 | 목적 |
| --- | --- |
| Discord 사용자 ID | 운영자 식별, 권한 확인 |
| Discord 로그인(OAuth2 `identify`, `guilds`)으로 받은 서버 목록과 서버별 권한 | 대시보드에서 관리할 수 있는 서버 확인 |
| 대시보드 세션 식별자(해시), 접속 IP(해시), 세션 생성·마지막 사용 시각 | 로그인 유지, 부정 사용 방지 |
| 부여된 Sentinel 운영자 역할(viewer·operator·admin) | 기능별 권한 확인 |
| 명령·대시보드 사용 기록(무엇을 언제 바꿨는지, 입력한 사유, 거부된 요청 포함) | 감사 기록, 분쟁 대응, 보안 사고 조사 |

#### 2.2 서버 멤버

| 항목 | 목적 |
| --- | --- |
| Discord 사용자 ID, 계정 생성 시각(ID에서 계산), 서버 입장·퇴장 시각 | 레이드·신규 계정 위험 판단 |
| 입장 상태(미인증·인증·격리 등)와 그 변경 이력, 위험 점수, 인증 시도 결과 | 입장 제어, 인증 결과 적용 |
| 서버 안에서 한 관리 행동의 기록: Discord 감사 로그 항목(행위자 ID, 대상, 사유, 변경 내역 — 닉네임 변경처럼 변경 내역에 이름이 들어갈 수 있습니다), 보유 역할 ID와 권한 | 서버 파괴 행위 탐지, 행위자 판단, 사건 기록 |
| 사건 기록(행위자·대상 ID, 판단 근거, 본 서비스가 한 조치와 결과) | 사건 검토, 오탐 판단, 증거 보존 |
| 메시지 신고 기록(신고자 ID, 대상자 ID, 신고 분류; 메시지 원문 제외) | 신고 처리 |
| (서버가 켠 경우) 메시지 내용을 해시로 바꾼 지문 | 같은 문구 반복·링크 스팸 탐지. 원문은 해시로 바꾼 즉시 버리며 저장하지 않습니다 |

#### 2.3 웹 인증·Invite Gate 이용자

서버가 웹 인증(CAPTCHA)이나 Invite Gate를 쓰는 경우, 서버에 들어오려는 사람은 Sentinel 웹 페이지에서 인증을 받습니다.

| 항목 | 목적 |
| --- | --- |
| Discord 로그인(OAuth2 `identify`, `guilds.join`)으로 받은 사용자 ID와 access token | 본인 확인, 인증 통과 후 서버 가입 처리. access token은 인증이 진행되는 동안에만 암호화해 보관하고, 인증이 끝나거나 만료되면 지웁니다 |
| (서버가 외부 신호를 켠 경우) OAuth2 `guilds`로 받은 가입 서버 목록 | 위험 계정 판단 |
| 접속 IP(해시) | 반복 시도·부정 사용 방지 |
| CAPTCHA 결과 | 사람인지 확인 |

#### 2.4 Sentinel Edge

서버가 Sentinel Edge 장치를 연결하면 장치의 공개키 지문, 이름, 버전, 최근 접속 시각, 장치가 쓰는 Edge 봇 계정 ID를 처리합니다. 장치 개인 키와 페어링 코드는 저장하지 않습니다.

### 6\. 정보주체의 권리와 행사 방법

이용자는 언제든지 자기 개인정보의 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다. 요청은 [8. 개인정보 보호책임자](#8-개인정보-보호책임자)의 연락처로 보내 주세요. 회사는 본인 확인 후 지체 없이 조치하고 결과를 알려드립니다.

다만 다음 경우에는 요청을 일부 거절하거나 제한할 수 있으며, 그 이유를 알려드립니다.

  * 다른 법령에 따라 보존해야 하는 경우
  * 서버 보안 사고의 기록(예: 서버를 파괴한 행위자의 기록)을 지우면 그 서버 운영자의 사고 조사나 분쟁 대응이 불가능해지는 경우

서버 멤버는 본 서비스를 설치한 서버의 운영자에게 먼저 문의할 수도 있습니다.

### 7\. 안전성 확보 조치

  * **해시 처리:** 세션, 인증 토큰, IP 주소는 원문 대신 키를 사용한 해시로만 보관합니다.
  * **암호화:** 웹 인증 중 보관하는 access token은 암호화합니다. 전송 구간은 HTTPS를 씁니다.
  * **접근 통제:** 운영자 기능은 Discord 권한과 Sentinel 운영자 역할을 모두 확인한 뒤에만 쓸 수 있고, 다른 서버의 정보는 조회할 수 없습니다.
  * **감사 기록:** 운영자의 변경과 거부된 요청은 수정·삭제할 수 없는 감사 기록에 남깁니다.
  * **최소 수집:** 메시지 원문, 사용자명, 아바타는 저장하지 않습니다.

## Sentinel 서비스 이용약관

> **초안 — 게시 전 NOAHSOFT Owner 승인 필요.** `[확인 필요]`로 표시한 항목이 모두 정해지기 전에는 이 문서를 병합(게시)하지 않습니다. 이 저장소는 파일이 병합되는 즉시 `noahsoft.kr/tos/sentinel/tos`에 노출됩니다.

이 약관은 NOAHSOFT(이하 "**회사**")가 제공하는 Discord 서버 보안 서비스 Sentinel(봇, 대시보드, Sentinel Edge를 포함하며 이하 "**본 서비스**")을 이용하는 조건과 회사·이용자의 권리, 의무, 책임을 정합니다.

---

### 제1조 (용어)

1. "**서버 운영자**"는 본 서비스를 Discord 서버에 설치하거나, Discord 명령·대시보드로 본 서비스를 관리하는 사람입니다.
2. "**서버 멤버**"는 본 서비스가 설치된 서버에 들어오거나 활동하는 사람입니다.
3. "**이용자**"는 서버 운영자와 서버 멤버를 함께 이르는 말입니다.
4. "**자동 조치**"는 본 서비스가 서버 운영자가 정한 정책에 따라 사람의 승인 없이 수행하는 조치입니다.

### 제2조 (약관의 효력과 변경)

1. 서버 운영자는 본 서비스를 서버에 설치하거나 계속 사용함으로써 이 약관에 동의한 것으로 봅니다. 동의하지 않으면 본 서비스를 서버에서 제거해 주세요.
2. 회사는 관련 법령을 위반하지 않는 범위에서 이 약관을 바꿀 수 있습니다. 바꾸는 경우 시행 7일 전까지, 이용자에게 불리한 변경은 시행 30일 전까지 NOAHSOFT 공식 Discord 커뮤니티에 변경 내용과 시행일을 알립니다.
3. 바뀐 약관에 동의하지 않는 서버 운영자는 본 서비스를 서버에서 제거할 수 있습니다.

### 제3조 (서비스 내용)

본 서비스는 다음 기능을 제공합니다. 서버마다, 그리고 파일럿 기간에는 일부 기능이 꺼져 있을 수 있습니다.

1. **Anti-Nuke:** 채널·역할 대량 삭제, 위험 권한 부여 같은 서버 파괴 행위를 감지하고 정책에 따라 알림을 보내거나 자동 조치합니다.
2. **입장 제어:** 레이드를 감지해 인증 단계를 조정하고, 필요하면 초대를 일시 중지합니다.
3. **사건 기록:** 감지한 내용, 판단 근거, 본 서비스가 한 조치와 결과를 기록합니다.
4. **승인 기반 복구:** 서버 구조의 스냅샷을 남기고, 서버 운영자가 승인한 복구 계획을 실행합니다.

### 제4조 (자동 조치의 범위)

1. 본 서비스가 할 수 있는 자동 조치는 다음뿐입니다: 알림 전송, 타임아웃, 위험 권한 역할 제거와 격리 역할 부여, 사건 중 행위자가 만든 웹훅 삭제, 초대 일시 중지(자동 만료), 서버 운영자가 켠 경우 위험 권한 역할의 권한 제거, 입장 제어 역할(미인증·인증·격리) 부여, 서버 운영자가 켠 경우 Discord 서버 인증 수준 상향(레이드가 끝나면 원래대로 되돌림).
2. 본 서비스는 서버 멤버를 **차단(ban)하거나 추방(kick)하지 않습니다.**
3. 자동 조치를 할지와 어디까지 할지는 서버 운영자가 정책(모드)으로 정합니다. 기본 모드는 Anti-Nuke는 알림만, 입장 제어는 기록만 하는 모드입니다.
4. 본 서비스는 Discord가 허용한 권한 안에서만 조치합니다. 본 서비스 역할보다 높은 역할을 가진 멤버나 권한이 없는 대상에는 조치하지 않고, 그 사실과 사유를 사건에 기록합니다.
5. 서버 구조 복구는 서버 운영자의 승인이 있어야 실행됩니다. 메시지, 멤버 목록, 멤버별 역할 배정, 초대는 복구 대상이 아닙니다.
6. 서버 운영자는 언제든지 자동 조치를 멈출 수 있습니다(`/대응 중지`). 멈춘 동안에도 감지와 기록은 계속됩니다.

### 제5조 (서버 운영자의 책임)

1. 서버 운영자는 서버 멤버에게 본 서비스가 서버에서 동작한다는 사실과 [개인정보 처리방침](https://noahsoft.kr/tos/sentinel/pp)을 알 수 있게 해야 합니다.
2. 서버 운영자는 본 서비스에 필요한 Discord 권한과 역할 위치를 직접 설정합니다. 권한이 부족해 생긴 조치 불가는 사건과 `/상태`에 표시됩니다.
3. 서버 운영자는 본 서비스의 사건 기록과 판단을 검토하고, 오탐이면 오탐으로 처리할 책임이 있습니다. 본 서비스가 격리한 멤버의 역할은 사건을 닫아도 자동으로 되돌아가지 않으므로, 필요하면 서버 운영자가 복원합니다.
4. 운영자 역할(viewer·operator·admin)은 Discord 서버 소유자가 부여합니다. 서버 소유자는 역할을 줄 사람을 신중히 정해야 합니다.

### 제6조 (금지 행위)

이용자는 다음 행위를 해서는 안 됩니다.

1. 본 서비스의 취약점을 찾아 악용하거나, 다른 서버의 정보에 접근하려는 행위
2. 인증·CAPTCHA를 자동화 도구로 우회하거나, 본 서비스 서버에 의도적으로 과도한 요청을 보내 운영을 방해하는 행위
3. 본 서비스를 이용해 다른 사람을 괴롭히거나 Discord 이용약관·관련 법령을 위반하는 행위

### 제7조 (이용 제한)

1. 이용자가 제6조를 위반하면 회사는 위반 내용을 알리고 시정을 요청할 수 있습니다. 시정되지 않으면 해당 서버나 이용자의 본 서비스 이용을 일시 또는 영구히 제한할 수 있습니다.
2. 다만 취약점 악용, 다른 서버 정보 접근 시도, 서비스 운영을 실제로 방해한 공격처럼 위반이 명백하고 다른 서버에 피해가 우려되는 경우에는 먼저 제한하고 그 뒤 지체 없이 사유를 알립니다.
3. 이용자는 제한에 대해 NOAHSOFT 공식 Discord 커뮤니티로 이의를 제기할 수 있고, 회사는 이를 검토해 결과를 알립니다.

### 제8조 (파일럿 기간)

1. 본 서비스는 현재 외부 파일럿 단계입니다. 파일럿 기간에는 기능, 제공 범위, 정책 기본값이 바뀔 수 있으며, 바뀌는 내용은 NOAHSOFT 공식 Discord 커뮤니티에 알립니다.
2. 파일럿 이용 요금: [확인 필요: 무료 여부. 유료라면 요금, 결제, 환불 조항을 별도로 둡니다]
3. 파일럿 종료나 정식 서비스 전환 시 조건: [확인 필요]
4. 파일럿 기간에는 서비스 수준(가용성·응답 시간)을 보장하지 않습니다.

### 제9조 (서비스 변경과 중단)

1. 회사는 장애, 점검, Discord API 변경 등으로 본 서비스의 전부나 일부를 일시 중단할 수 있습니다. 미리 알 수 있는 점검은 사전에, 그렇지 않은 장애는 사후 지체 없이 NOAHSOFT 공식 Discord 커뮤니티에 알립니다.
2. 회사가 본 서비스 제공을 끝내는 경우 끝내기 30일 전까지 알립니다.

### 제10조 (책임의 한계)

1. 본 서비스는 서버 보안을 돕는 도구이며, 모든 공격을 감지하거나 막는 것을 보장하지 않습니다. 정책에 정한 속도보다 느린 파괴 행위, Discord가 감사 로그에 남기지 않는 행위, 본 서비스에 권한이 없는 대상은 감지하거나 조치하지 못할 수 있습니다.
2. 회사는 다음으로 생긴 손해에 대해서는 책임을 지지 않습니다. 다만 회사의 고의 또는 중대한 과실이 있는 경우는 예외입니다.
   1. 서버 운영자가 설정한 정책, 권한, 역할 위치에 따라 본 서비스가 한 자동 조치나 하지 못한 조치
   2. 서버 운영자가 승인한 복구 계획의 실행 결과
   3. Discord의 장애, API 제한, 정책 변경
   4. 이용자가 제6조를 위반해 생긴 손해
3. 회사는 자기 책임으로 이용자에게 손해가 생긴 경우 관련 법령에 따라 배상합니다.

### 제11조 (개인정보)

본 서비스의 개인정보 처리는 [Sentinel 개인정보 처리방침](https://noahsoft.kr/tos/sentinel/pp)을 따릅니다.

### 제12조 (문의)

본 서비스에 관한 문의, 오류 신고, 이의 제기는 NOAHSOFT 공식 Discord 커뮤니티(https://discord.gg/z3HpT4ZhGF)로 보내 주세요. [확인 필요: 이메일 연락처 추가 여부]

이 약관은 대한민국 법률에 따라 해석됩니다. 본 서비스와 관련된 분쟁은 민사소송법에 따른 관할 법원에서 해결합니다.

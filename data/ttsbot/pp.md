# 니아(Nia) 개인정보처리방침

**최종 수정일:** 2026년 10월 12일

---

니아(Nia, 이하 "**본 서비스**")는 이용자의 개인정보를 소중히 여기며 **개인정보보호법** 및 관련 법규를 준수합니다.

---

## 1. 수집하는 개인정보 항목

**본 서비스**는 기능 제공에 필요한 정보를 처리하며, 이용하는 기능에 따라 항목이 달라질 수 있습니다.

* **이용자 정보:** Discord ID (TTS 요청자 식별용)
* **서버 정보:** 서버(길드) ID, 음성 채널 ID
* **TTS 입력 텍스트:** 음성 합성 과정에서만 이용하며, 일반 사용량 데이터베이스에 원문을 별도 저장하지 않음
* **음성·서버 설정:** 개인 음성 설정, 서버 설정, 블랙리스트, 단어 대체 및 사용 제한 정보
* **사용 기록:** 요청자 Discord ID, 요청 일시, 음성·글자 수, 성공·실패, 캐시 적중, 처리 지연 등 사용량·운영 기록
* **멤버십·결제·PAYU:** 구매자 Discord ID, 대상 서버, 상품·가격·유효기간, 실제 송금자명, 쿠폰·주문·충전·환불 및 정산 이력
* **NOAHSOFT Account 연동(Beta):** 연동한 Discord 사용자 ID, NOAHSOFT Account 내부 사용자 식별자, 연동 시각
* **추가 기능:** 서비스 설문 응답과 서버 관리자가 동의한 선택적 진단 정보
* **Nia Public API(이용 시):** API 프로젝트·인증키 식별/검증 정보, 사용량·요청·과금 기록. 요청 로그에 TTS 원문과 API 키 원문은 저장하지 않음

---

## 2. 개인정보 이용 목적

1. TTS 기능 제공 (텍스트 → 음성 변환)
2. 서버별 TTS 설정 관리
3. 서비스 품질 개선 및 오류·보안 사고 대응
4. 멤버십·무료체험·선불 사용량 제공, 결제·정산·환불 및 고객지원
5. NOAHSOFT Account 연동 및 Nia Public API 제공(해당 기능 이용 시)
6. 선택적 진단과 설문 기능 제공(이용 시)

---

## 3. 개인정보 보유 기간

* **TTS 입력 텍스트:** 변환 즉시 파기, 저장하지 않음
* **생성 오디오 캐시:** 음성 파일은 약 7일 경과를 기준으로 주기적으로 정리하며, 실제 파기 시점은 정리 작업 주기에 따라 달라질 수 있음
* **Nia Public API 오디오·멱등성 정보(이용 시):** 생성 오디오 결과는 기본 24시간, 중복 과금 방지 기록은 기본 7일 후 정리하도록 구현됨
* **서버 설정 데이터:** 봇이 서버에서 제거될 때 정리되는 설정이 있으나, 다른 서브 봇과 공유 중인 설정은 유지될 수 있음
* **결제·PAYU·사용량·감사 이력:** 봇 제거와 동시에 일괄 삭제되지 않으며, 정산·이용권 복원·분쟁 대응 및 법적 보존 의무에 필요한 범위에서 보유
* **NOAHSOFT Account 연동 관계:** 니아에서 연동 해제 시 니아 쪽 매핑 정보 삭제. Account 자체의 Discord 연동 정보는 별도 관리
* **삭제 요청 시:** 원칙적으로 72시간 이내 처리. 법령상 보존 의무 또는 본인 확인 등으로 즉시 처리할 수 없는 경우에는 사유와 처리 범위를 안내

## 4. 제3자 제공

수집된 개인정보는 법령에 따른 경우를 제외하고 제3자에게 제공하지 않습니다.

**음성 합성에는 Google Cloud Text-to-Speech, Google Gemini API 등 외부 제공자가 이용될 수 있고, 선택한 엔진에 따라 TTS 처리를 위한 텍스트가 전달될 수 있습니다.** 로컬 음성 엔진으로 처리하는 경우 외부 음성 합성 API를 거치지 않을 수 있습니다.

처리위탁 및 국외 이전이 적용되는 경우 수탁업체, 전송 항목, 처리 국가·기간, 법적 근거 등 법령이 정한 사항을 확인하여 적절하게 고지·동의 절차를 진행합니다. 외부 업체의 실제 처리 지역과 계약상 보관 조건은 운영 설정·계약을 기준으로 검증해야 합니다.

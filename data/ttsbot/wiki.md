# 니아(Nia) 공식 위키

**최종 내용 점검:** 2026년 10월 12일

니아(Nia)는 음성 채널에서 텍스트 채팅을 음성으로 읽어주는 Discord TTS 봇입니다. 이 문서는 니아의 기능과 명령어 사용법을 안내합니다.

## 시작하기

1. 봇을 서버에 초대합니다.
2. 음성 채널에 들어간 뒤, 읽어줄 텍스트 채널에서 `/들어와`를 입력하면 봇이 내 음성 채널에 들어옵니다.
3. 이후 해당 텍스트 채널에 올라오는 메시지를 봇이 음성으로 읽어줍니다.
4. `/나가`로 봇을 내보낼 수 있습니다.

메시지 맨 앞에 `//`를 붙이면 그 메시지는 읽지 않습니다.

> 서버 설정에서 **TTS 채널**을 지정해두면 `/들어와`를 어느 채널에서 실행하든 항상 그 채널만 읽고, **자동 입장**을 켜면 `/들어와` 없이도 봇이 알아서 들어옵니다. 자세한 내용은 아래 [서버 설정](#서버-설정-서버설정)을 참고하세요.

## TTS 설정 (`/설정`)

- **음성**: 여성 / 남성 / 잔잔 중 선택. 각각 일반 음질과 고급 음질(멤버십 전용)이 있습니다.
- **속도**
  - 무료: 0.75 \~ 1.5
  - 멤버십: 0.25 \~ 4.0
- **피치**
  - 무료: -5 \~ 5
  - 멤버십: -20 \~ 20

`/설정`에서 따로 정하지 않은 사람에게는 서버 관리자가 `/서버설정`에서 지정한 서버 기본 음성·속도·피치가 적용됩니다.

## 글자수 제한

| 구분 | 무료 | 멤버십 |
| --- | --- | --- |
| 메시지 최대 길이 (초과 시 ❌ 반응만 남고 읽지 않음) | 200자 | 500자 |
| 실제로 읽어주는 글자수 (초과분은 잘라서 읽음) | 150자 | 400자 |

서버 관리자가 특정 멤버에게 **멤버별 글자 수 한도**를 걸어둔 경우, 읽을 글자수가 그 한도를 넘는 메시지는 반응 없이 조용히 건너뜁니다.

## 메시지를 읽는 방식

- 멘션(유저/역할/채널)은 이름으로 바뀌어 읽힙니다. 예: `@닉네임` → "닉네임님을 언급했어요."
- 다른 메시지에 답장한 경우 "OO님이 XX에게 답장을 보냈어요."가 앞에 붙어 읽힙니다.
- 첨부파일은 종류에 따라 "사진을 보냈어요", "소리파일을 보냈어요", "영상을 보냈어요", "파일을 보냈어요"로 읽힙니다. 여러 종류가 섞이면 함께 나열됩니다. (예: "사진, 영상을 보냈어요")
- 스티커는 "스티커를 보냈어요"로 읽힙니다.
- 이모지(❤️, 😭 등)와 텍스트 이모티콘(`:)`, `(-_-)` 등)은 뜻이 담긴 단어로 바뀌어 읽힙니다.
- 서버에 등록된 **TTS 단어 대체**가 먼저 적용된 뒤 읽힙니다.
- 메시지 전체가 서버에 등록된 **사운드보드** 트리거 단어와 정확히 일치하면, TTS 대신 등록된 소리를 재생합니다.
- 블랙리스트에 등록된 유저의 메시지는 읽지 않습니다.

## 서버 설정 (`/서버설정`)

서버 관리 권한이 있는 사람만 열 수 있으며, 두 페이지로 나뉘어 있습니다.

### 1페이지 · 음성·채널

| 항목 | 설명 |
| --- | --- |
| 기본 음성 / 속도 / 피치 | 개인 설정이 없는 멤버에게 적용되는 서버 기본값입니다. 고급 음성을 기본값으로 쓰려면 서버 멤버십이 필요합니다 |
| 인원제한 자동 조정 | 인원제한이 걸린 음성 채널에 봇이 들어가면 제한을 1명 늘려, 봇 때문에 사람이 못 들어오는 일을 막습니다. 봇이 나가면 원래대로 돌려놓습니다 (봇에게 채널 관리 권한 필요) |
| 업데이트 공지 채널 | 봇 업데이트 안내를 받을 채널입니다. 설정하지 않으면 서버 주인에게 DM으로 보냅니다 |
| TTS 채널 제한 | 설정하면 이 채널의 메시지만 읽습니다. `/들어와`를 다른 채널에서 실행해도 이 채널을 읽습니다 |
| 자동 입장 | TTS 채널을 지정한 경우에만 켤 수 있습니다. 봇이 음성 채널에 없을 때 TTS 채널에 메시지를 보낸 사람이 음성 채널에 있으면, 봇이 자동으로 들어가서 읽기 시작합니다 |

### 2페이지 · 관리·보안

| 항목 | 무료 서버 | 서버 멤버십 | 설명 |
| --- | --- | --- | --- |
| 사운드보드 | 10개 | 50개 | 트리거 단어(최대 20자)와 오디오 파일(최대 2MB)을 등록합니다. 같은 트리거는 5초에 한 번만 재생되고, 쿨다운 중이면 ⏳ 반응이 남습니다 |
| TTS 단어 대체 | 20개 | 100개 | 특정 단어를 다른 단어로 바꿔 읽습니다 (예: `ㄱㅅ` → `감사합니다`). 한 개씩 또는 `원문=읽을단어` 형식으로 대량 등록(붙여넣기 / .txt 파일)할 수 있습니다 |
| 봇 프로필 사진 | ❌ | ✅ | 이 서버에서 보이는 봇의 프로필 사진을 바꿉니다 |
| 블랙리스트 | ❌ | ✅ | 이 서버에서 메시지를 읽지 않을 유저를 관리합니다 |
| 멤버별 글자 수 한도 | ❌ | ✅ | 특정 멤버의 메시지 읽기 글자수를 1\~2,000자로 제한합니다 |
| 비필수 정보 전송 | ✅ | ✅ | 디버깅에 도움되는 정보를 로그에 남기도록 동의합니다. 동의 후 최소 2주가 지나면 매월 1일에 **서버 멤버십 3일**이 지급됩니다 |

### 서브 봇

한 음성 채널에서만 봇을 쓸 수 있는 한계를 넘기 위해, 서버에 서브 봇을 추가로 초대할 수 있습니다.

- 서브 봇은 `/들어와`, `/나가`만 지원합니다. 서버 설정은 마스터 봇에서 관리합니다.
- `/서버설정` 2페이지의 **서브 봇별 설정**에서 서브 봇마다 기본 음성, 속도/피치, 인원제한 자동 조정, 프로필 사진, 멤버별 글자 수 한도를 따로 정할 수 있습니다.
- 사운드보드, 블랙리스트, TTS 단어 대체는 마스터 봇 설정을 모든 서브 봇이 함께 씁니다.
- 같은 음성 채널에 이미 다른 봇이 있으면 TTS가 중복 재생될 수 있어, 들어가기 전에 확인을 요청합니다.

## 멤버십

멤버십에 가입하면 다음이 확장됩니다.

- 🎙️ 음성 품질: 일반 → **고급 음성**
- ⚡ 속도 조절: 0.75\~1.5배 → **0.25\~4.0배**
- 🎚️ 피치 조절: -5\~5 → **-20\~20**
- ✍️ 메시지 인식 길이: 200자 → **500자**
- 🗣️ 실제 낭독 길이: 150자 → **400자**
- 🛠️ `/서버설정`의 프로필 사진 변경, 블랙리스트, 멤버별 글자 수 한도: **서버 멤버십 전용**
- 🔊 사운드보드 10개 → **50개**, 🔤 TTS 단어 대체 20개 → **100개**: **서버 멤버십 전용**

> 고급 음성은 서버/개인 단위로 월간 사용량 소프트 캡이 있으며, 캡을 초과한 달에는 자동으로 일반 음성으로 전환됩니다.

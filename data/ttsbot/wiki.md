# TTS 봇 공식 위키

음성 채널에서 텍스트 채팅을 음성으로 읽어주는 Discord 봇입니다. 이 문서는 봇의 기능과 명령어 사용법을 안내합니다.

## 시작하기

1. 봇을 서버에 초대합니다.
2. 읽어줄 텍스트 채널에서 `/들어와`를 입력하면 봇이 자신의 음성 채널에 들어옵니다.
3. 이후 해당 텍스트 채널에 올라오는 메시지를 봇이 음성으로 읽어줍니다.
4. `/나가`로 봇을 내보낼 수 있습니다.

메시지 맨 앞에 `//`를 붙이면 그 메시지는 읽지 않습니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `/들어와` | 봇이 내 음성 채널에 들어옵니다 |
| `/나가` | 봇이 음성 채널에서 나갑니다 |
| `/스킵` | 현재 재생 중인 TTS를 건너뜁니다 |
| `/설정 음성/속도/피치` | 목소리 종류, 말하기 속도, 피치를 설정합니다 |
| `/설정공유 공유` | 내 TTS 설정을 공유코드로 발급합니다 |
| `/설정공유 적용` | 다른 사람이 공유한 공유코드를 적용합니다 |
| `/설정가져오기` | 다른 서버에서 쓰던 내 설정을 이 서버로 가져옵니다 |
| `/이동` | 음성 채널의 멤버(또는 나 자신)를 다른 채널로 이동시킵니다 |
| `/봇프로필사진` | 이 서버에서 쓰이는 봇의 프로필 사진을 변경합니다 (서버 멤버십 필요) |
| `/서버블랙리스트 추가/제거/목록` | 이 서버 전용 블랙리스트를 관리합니다 (서버 멤버십 + 서버 관리 권한 필요) |

봇이 자신의 음성 채널에 있는 동안 모든 인원이 채널을 나가면 봇도 자동으로 퇴장합니다.

## TTS 설정 (`/설정`)

- **음성**: 여성 / 남성 / 잔잔 중 선택. 각각 일반 음질과 고급 음질(멤버십 전용)이 있습니다.
- **속도**
  - 무료: 0.75 \~ 1.5
  - 멤버십: 0.25 \~ 4.0
- **피치**
  - 무료: -5 \~ 5
  - 멤버십: -20 \~ 20

## 글자수 제한

| 구분 | 무료 | 멤버십 |
| --- | --- | --- |
| 메시지 최대 길이 (초과 시 ❌ 반응만 남고 읽지 않음) | 200자 | 500자 |
| 실제로 읽어주는 글자수 (초과분은 잘라서 읽음) | 150자 | 400자 |

## 메시지를 읽는 방식

- 멘션(유저/역할/채널)은 이름으로 바뀌어 읽힙니다. 예: `@닉네임` → "닉네임님을 언급했어요."
- 다른 메시지에 답장한 경우 "OO님이 XX에게 답장을 보냈어요."가 앞에 붙어 읽힙니다.
- 첨부파일만 있는 메시지는 "파일을 보냈어요"로 읽힙니다.
- 서버 전체가 블랙리스트로 등록한 유저의 메시지는 읽지 않습니다.
